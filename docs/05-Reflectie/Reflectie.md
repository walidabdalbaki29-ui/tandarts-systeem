# Reflectie – Nova Tandzorg

## 1. Wat heb ik gedaan?

Tijdens dit project heb ik een website voor een tandartspraktijk ontwikkeld met Laravel en MySQL.

Patiënten kunnen zich registreren, inloggen, behandelingen bekijken en afspraken maken of annuleren.

De beheerder kan behandelingen toevoegen, wijzigen en verwijderen. Ook kan de beheerder afspraken bevestigen en annuleren.

Naast het programmeren heb ik gewerkt aan user stories, wireframes, een ERD, een sitemap, een flowchart en tests.

## 2. Wat ging goed?

Ik heb veel nieuwe dingen geleerd over Laravel en het MVC-model.

Ik begrijp nu beter hoe Routes, Controllers, Models en Views samenwerken.

Ook heb ik geleerd hoe ik met Laravel gegevens kan opslaan en ophalen uit een database.

Ik ben tevreden dat ik verschillende functies van mijn website werkend heb gekregen.

## 3. Wat vond ik moeilijk?

In het begin vond ik Laravel moeilijk, omdat ik nog niet veel ervaring had met dit framework.

Vooral het maken van afspraken en het controleren van overlappende tijden vond ik lastig.

Ook vond ik het schrijven van Unit Tests en Feature Tests moeilijk, omdat ik eerst moest begrijpen hoe deze tests werken.

## 4. Hoe heb ik problemen opgelost?

Wanneer ik een probleem tegenkwam, probeerde ik eerst de foutmelding te begrijpen.

Daarna controleerde ik mijn code en zocht ik naar een oplossing.

Ik testte mijn wijzigingen om te controleren of het probleem was opgelost.

Door deze stappen heb ik geleerd om problemen beter en zelfstandiger aan te pakken.

## 5. Wat heb ik geleerd?

Tijdens dit project heb ik geleerd:

* Hoe Laravel werkt met het MVC-model.
* Hoe ik een database gebruik met Models.
* Hoe ik formulieren controleer met validatie.
* Hoe ik verschillende gebruikersrollen kan gebruiken.
* Hoe ik Unit Tests en Feature Tests schrijf.
* Hoe ik mijn code controleer met Laravel Pint.
* Hoe belangrijk planning en documentatie zijn.

## 6. Wat kan ik verbeteren?

Bij een volgend project wil ik eerder beginnen met testen en documenteren.

Ook wil ik mijn werk beter verdelen over de beschikbare tijd.

Daarnaast wil ik zelfstandiger leren programmeren, zodat ik minder hulp nodig heb bij moeilijke onderdelen.

## 7. Conclusie

Ik ben tevreden met wat ik tijdens dit project heb geleerd.

Laravel was in het begin moeilijk voor mij, maar door te oefenen begrijp ik het framework steeds beter.

Ik heb geleerd dat programmeren niet alleen gaat over code schrijven, maar ook over plannen, testen en problemen oplossen.

Deze ervaring helpt mij om bij volgende projecten beter en zelfstandiger te werken.
