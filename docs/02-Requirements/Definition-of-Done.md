# Definition of Done (DoD) – Nova Tandzorg

## 1. Functionaliteit
- De functionaliteit werkt volgens de User Story.
- De Acceptance Criteria zijn gecontroleerd.
- De gebruiker krijgt duidelijke foutmeldingen bij ongeldige invoer.

## 2. Validatie en beveiliging
- Invoer wordt gevalideerd.
- Alleen bevoegde gebruikers hebben toegang tot beveiligde functies.
- Patiënten kunnen alleen hun eigen afspraken bekijken en beheren.

## 3. Codekwaliteit
- De code volgt de afgesproken codeerstijl.
- Laravel Pint wordt uitgevoerd.
- De code is overzichtelijk en onderhoudbaar.

## 4. Testing
- Relevante Unit Tests en Feature Tests zijn uitgevoerd.
- De tests slagen.
- Belangrijke foutscenario's zijn getest.

## 5. Git en documentatie
- De wijzigingen zijn opgeslagen in Git.
- De User Story en Acceptance Criteria zijn gecontroleerd.
- Benodigd bewijs, zoals screenshots van tests, is opgeslagen.

## 6. Afronding
Een taak is Done wanneer aan de relevante criteria hierboven is voldaan
en de functionaliteit voldoet aan de projecteisen.
